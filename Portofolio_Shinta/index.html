Tentang Saya

Saya adalah mahasiswi semester 4 Program Studi Teknik Informatika di Politeknik Negeri Jember dengan IPK kumulatif 3,60. Saya memiliki pengalaman di berbagai bidang, termasuk IoT, Desktop Development, UI/UX Design, Web Development, dan Quality Assurance. Dari pengalaman tersebut, saya telah memahami beberapa bahasa pemrograman seperti C, C++, HTML, CSS, Java, PHP, dan Dart. Selama ini, saya telah terlibat dalam pengembangan proyek IoT serta berbagai jenis aplikasi bersama tim, baik dalam bentuk desktop, web, maupun mobile. Saya sangat antusias terhadap tantangan dan hal-hal baru yang dapat memperluas wawasan serta meningkatkan keterampilan saya di bidang teknologi.
